mpv is NOT redistributed inside the Movy Windows ZIP. On first Play, with the
user's permission, the app downloads the official mpv 0.41.0 Windows x64 MinGW
build directly from the mpv project's GitHub Release, verifies its pinned
SHA-256 checksum, and stores it in the user's local application-data directory.
mpv is a separately licensed GPL/LGPL media player; see its upstream license,
source code, release notes and build/dependency sources:
https://github.com/mpv-player/mpv/releases/tag/v0.41.0
https://github.com/mpv-player/mpv/tree/v0.41.0
https://github.com/mpv-player/mpv/blob/v0.41.0/Copyright
https://github.com/mpv-player/mpv/tree/v0.41.0/.github/workflows
