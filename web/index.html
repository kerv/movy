Install on Android TV

  1. Download the APK onto the device (use the button above, or a sideload tool like Downloader with this page's URL).
  2. Allow installs from unknown sources when prompted.
  3. Open Movy TV. From then on it updates itself whenever a new version is published here.
Updates only install if the new APK is signed with the same key as the one already on your device. If you previously ran a build signed with a different key, uninstall it once before installing this one.

Movy TV is an unofficial client and is not affiliated with movy.sx. It streams no content itself.
