Install on Android TV

  1. Download the APK onto the device (use the button above, or a sideload tool like Downloader with this page's URL).
  2. Allow installs from unknown sources when prompted.
  3. Open Movy TV. The app checks version.json on launch and offers new signed updates.
Updates only install if the new APK is signed with the same key as the one already on your device. If you previously ran a build signed with a different key, uninstall it once before installing this one.

Run on Windows 10/11 x64

  1. Download and extract the whole ZIP. Run Movy.exe in the extracted folder; keep the accompanying files.
  2. WebView2 Runtime is required for account access and stream resolution. If missing, install it from Microsoft. The .NET runtime is included.
  3. First Play offers the official mpv download (~39 MB). The app verifies a pinned SHA-256 checksum and caches the player locally.
  4. Sign in separately on Windows. Android credentials/local history do not transfer automatically. Space pauses, arrows seek, F11 toggles fullscreen, and Esc twice returns to the title.
Windows is an unsigned preview, not an installer. An unknown-publisher warning may appear; verify the expected download and checksum instead of disabling Windows security. Windows updates are manual: extract the new ZIP to a new folder. Real account/stream/video compatibility still needs device testing.
